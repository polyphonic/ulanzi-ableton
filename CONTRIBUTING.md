# Contributing

Use one issue per problem and search existing reports first. Describe what you did, what you expected and what happened. A minimal reproduction or short video helps us verify the cause.

Reports are welcome even if you are unsure whether a problem is configuration, the plugin or Ulanzi Studio. We will triage it without assuming user error. For an existing report, add your versions and reproduction instead of a duplicate.

This repository accepts support documentation improvements. Plugin source and private development history are not published here. Do not post other users’ private emails, recordings, credentials or full personal logs.
