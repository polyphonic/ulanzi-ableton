# Ableton Live for Ulanzi

Bug reports and feature requests for Polyphonic’s Ableton Live integration for **Ulanzi Dial, D200, D200H and D200X**. This repository contains support documentation; the plugin source is private.

[Report a bug](https://github.com/polyphonic/ulanzi-ableton/issues/new?template=bug_report.yml) · [Request a feature](https://github.com/polyphonic/ulanzi-ableton/issues/new?template=feature_request.yml) · [Known issues](KNOWN_ISSUES.md)

Search [existing issues](https://github.com/polyphonic/ulanzi-ableton/issues) before reporting. The form asks for your device, exact versions, profile, steps to reproduce, and expected versus actual behavior. A short video or screenshots help, but are optional. Report one problem per issue and redact personal details from logs.

**Basic / Offline?** “Installed” confirms the Remote Script files are present; “Connected” confirms communication with Live. See [setup and connection checks](SUPPORT.md). For these reports, screenshots of the Integration tab and Live’s Control Surface settings are useful.

Get the plugin through [Ulanzi Marketplace](https://ugc.ulanzistudio.com/contentView/1144). Generic mouse-wheel actions, other profiles and Studio/device problems belong with [Ulanzi support](https://bbs.ulanzistudio.com/).
